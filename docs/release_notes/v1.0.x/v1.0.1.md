## [1.0.1] - 2026-10-13 - Unpublished Release Attempt

### Overview

The `v1.0.1` tag has no published release. It was tagged on a commit whose `VERSION` still read `v1.0.0`, so release preflight rejected it before any build. The release workflow problems behind `v1.0.0` through `v1.0.3` are fixed in [v1.0.4](v1.0.4.md), the first published 1.0 release, which contains everything in this tag.
