## [1.0.2] - 2026-10-13 - Unpublished Release Attempt

### Overview

The `v1.0.2` tag has no published release. Its binaries were built and signed, but the release workflow failed re-verifying the downloaded artifact set, so no GitHub release or website download was published. The release workflow problems behind `v1.0.0` through `v1.0.3` are fixed in [v1.0.4](v1.0.4.md), the first published 1.0 release, which contains everything in this tag.
