## [1.7.3] - 2026-11-02 - Judge Resilience, Gateway Trust Caching, and Model Catalog Expansion

## Overview

v1.7.3 enhances evaluation judge execution resilience with token truncation diagnostics and configurable output limits, caches the Gateway trust bundle in memory to avoid burst read contention, preserves live event publication across legacy grader call records, expands the base model inventory and framework catalog, and aligns Evaluation Explorer consensus stream headers.

## Added

- Distinct error reporting for judge model responses truncated by token limits or incomplete JSON output.
- Bounded and configurable output token constraints for judge inference dispatches.
- Support for MiniCPM, OLMo 3, Spark X2.6, and LFM2.5 MoE model families in the evaluation inventory and framework catalog.

## Changed

- Evaluation Explorer live event stream column header updated to "Consensus" for tribunal vote activity.
- Gateway trust bundle cached in-memory within `PKIAuthority` to mitigate filesystem contention during connection bursts.

## Fixed

- Prevented evaluation campaign failure when judge evaluations encounter execution errors.
- Handled legacy evaluation grader call records lacking rubrics or signed evidence during live event publication without raising schema validation errors.

## Compatibility

v1.7.3 is fully backwards-compatible with v1.7.2, v1.7.1, and v1.7.0 across CLI, wire, and evidence contracts. Gateway and Operators can be upgraded independently within the 1.7.x series.
