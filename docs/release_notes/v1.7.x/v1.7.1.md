## [1.7.1] - 2026-11-01 - JIT-LLM Backend, Judge Resilience, and Evaluation Explorer Updates

## Overview

v1.7.1 introduces the JIT-LLM (`jitllm`) local inference backend with container execution and GGUF provenance attestation, enhances evaluation judge execution resilience, improves the Evaluation Explorer runs panel and live event stream display, refines investigation evaluation scenarios, and fixes filesystem disk profile error handling on unreadable subdirectories.

## Added

- A JIT-LLM (`jitllm`) inference backend provider with container runner support, GGUF model digest verification, model provenance attestation, and operator capability ownership integration.
- Live event stream and run display test suites in the Evaluation Explorer (`campaign-wire.test.ts`, `live-event-stream.test.tsx`, `overview-view.test.tsx`).
- Support for `/snap/gnome-46-2404` library paths in Playwright configurations and the root Makefile for Linux component test environments.

## Changed

- Evaluation rollout drafting and named rollout execution provide clearer error feedback and validation.
- Investigation scenario `cron-disk-fill` provides explicit case notes and objective goals, and enables `file_edit` in the allowed tool blueprint.
- Base model inventory and formation catalog overlays downsized and updated for active evaluation suites.
- Code cleanup across judge, security, and internal constants removing deprecated paths and unused test hooks.

## Fixed

- Evaluation judge execution handles provider retries and transient failures with improved resilience.
- Evaluation Explorer correctly displays live event streaming, judge activity details, and aggregate campaign run statistics.
- The `fs_disk_profile` native MCP tool skips unreadable subdirectories beneath the search root instead of aborting the entire directory walk.
- Removed erroneous `--all` flag option from `ztd eval campaigns create`.
- Wire contract typing and null handling resolved in Evaluation Explorer `campaign-wire.ts`.

## Compatibility

v1.7.1 is fully backwards-compatible with v1.7.0 across CLI, wire, and evidence contracts. Gateway and Operators can be upgraded independently within the 1.7.x series.
