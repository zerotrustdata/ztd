## [1.7.2] - 2026-11-01 - Process Termination Safeguards and Evaluation Test Stability

## Overview

v1.7.2 introduces process management and signal safeguards preventing unintended signaling or termination of system PIDs and the caller process, and resolves evaluation test stability issues across integration and end-to-end suites.

## Added

- Safe PID boundary validation in `ProcessManager` ensuring PID 1, negative PIDs, and invalid process IDs are ignored during process lookups, status checks, and stop operations.
- Added host process PID (`os.Getpid()`) to the `proc_signal_safe` tool denylist to prevent calling processes from signaling themselves.

## Changed

- Quoted regex metadata in process manager pattern matching for `--data-dir` argument inspection.

## Fixed

- Prevented process manager from signaling PID 0 or PID 1 on invalid or absent PID values.
- Awaited Gateway heartbeat recording and topology resolution in evaluation held episode rebound tests to eliminate flakiness.
- Synchronized capability probe tool replies in the cross-process evaluation loop end-to-end test sequence.

## Compatibility

v1.7.2 is fully backwards-compatible with v1.7.1 and v1.7.0 across CLI, wire, and evidence contracts. Gateway and Operators can be upgraded independently within the 1.7.x series.
